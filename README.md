# Crow Animation

Crow Animation built using HTML, CSS and JavaScript.

![Crow Animation Screenshot](https://github.com/BinaryVortex/Crow-Animation/blob/main/Screenshot%202024-08-29%20081521.png)

## Demo

Open `index.html` in your browser to see the animation. For a local web server (recommended to avoid any local file restrictions), run one of these commands in the repository root:

- Python 3.x:

  ```bash
  python -m http.server 8000
  ```

- Node (http-server):

  ```bash
  npx http-server -p 8000
  ```

Then visit http://localhost:8000 in your browser.

## Features

- Smooth crow animation created with pure CSS and a small amount of JavaScript.
- Lightweight and easy to customize.

## Files

- `index.html` — markup and any inline scripts.
- `style.css` — main styling and animation.
- `Screenshot 2024-08-29 081521.png` — repository screenshot used in this README.

## How to Customize

- Edit `style.css` to change colors, timing, and animation details.
- Modify `index.html` to change structure or add additional elements.
